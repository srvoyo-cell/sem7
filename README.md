---
Буду загружать за 7 вариант. Если хотите контрибьютить, то соблюдайте структуру.

```
└── предмет
    └── вариант
```

## Скиллы
### lab-work
Написание лабораторных или практических работ. Используется язык Python + marimo. Реактивный аналог jupyter. Модный современный :)

### typst-report-dev
Написание отчетов в pdf. Отдельно нужно указать свою фамилию, название предмета, вариант и должность + степень + ФИО преподавателя
